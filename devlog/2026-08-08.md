## 问题与决策
- **EMI 依赖**：因网络不可达，放弃 maven 坐标，改用本地 jar（`libs/emi-1.1.24+1.21.1+neoforge.jar`）。`localRuntime` 用于 `runClient` 测试、不打进 mod 包。
- **自动合成范围**：仅自动合成工作台配方（`CraftingRecipe`）；烧炼/锻造/模组机器等非工作台配方不自动合成；中间步骤不递归合成，材料须备齐。
- **Mixin 版本敏感性**：注入 EMI 内部类（`EmiScreenManager`、`BoM` 等，javap 实证），锁定 EMI 1.1.24；升级需回归。
- **分阶段策略**：Phase 0 基建 → Phase 1 树按钮+基础树 → Phase 2 多树+快捷键+宽度 → Phase 3 自动合成；每阶段独立验证。
