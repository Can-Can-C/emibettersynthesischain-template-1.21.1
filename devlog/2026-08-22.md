# 多版本补充验证（2026-08-22 会话 3 续 · 1.20.1 dev 覆盖层实验）

## 尝试：dev-refmap 覆盖层打通 EMI 1.20.1 dev-runClient（结论：不可行，已回退）
- 思路：EMI xplat refmap 缺 @Shadow/@Accessor 的 SRG 字段条目（如 f_91073_）→ 制作 dev 覆盖层 jar（`emi-dev-overlay.jar`，内含补全字段条目的 `emi-xplat-refmap.json`），并在 runtimeClasspath 上置于 EMI 之前（已验证顺序正确）。
- **javap 实证（mixin 0.8.5）**：`MixinPreProcessorStandard.attachFields` 的 shadow 字段走 `MixinTargetContext.findRemappedField` → `RemapperChain.mapFieldName(className, name, desc)`——**dev 的 RemapperChain 只由 refmap 的值生成**（方法条目值带完整 `L目标类;方法(desc)V` 才能注册映射）；而字段值格式只有 `f_xxx:Ltype;`（无目标类）→ 链上无 (目标类, f_xxx) 条目 → 裸 SRG 字段字符串在 dev 运行时**无法映射**。这解释了为何 refmap 方法条目 dev 可用、字段不可用。
- **结论**：EMI 1.20.1 官方 jar 的 SRG 字段 mixin 在官方名 dev 运行时无解（硬性外部限制，非本 mod 代码）→ 覆盖层方案已删除（build.gradle 回退、jar 删除）。**1.20.1 分支验收唯一路径 = 真机安装构建产物**（玩家环境 = SRG 运行时，EMI 正常）。
