# 开发需求说明书（Requirements）

> 项目：EMI Better Synthesis Chain（NeoForge 1.21.1 / EMI 1.1.24 附属 mod）
> 状态：与用户逐条确认，随实现更新。变更记录见文末。

## 1. 项目概述
本 mod 是 **EMI 附属 mod**：重写 EMI 的配方树（合成树）展示，并新增"悬停即自动合成"。通过 Mixin 注入 EMI 内部类实现定制。

## 2. 功能需求

### 需求 1：配方树按钮行为
- **目标**：点左下角"配方树"按钮 → **不再弹独立 BoM 界面**，切换侧边栏到"收藏页"显示合成树。
- 添加配方树（配方页按钮 / EMI keybind）时页面**打开则保持，未打开则打开**；左下角按钮为开关。
- **验收**：无全屏树窗口；收藏页显示合成树；添加不关闭页面。

### 需求 2：合成树布局
- 布局（用户示例为验收基准）：
  ```
  [栅栏×3] │ [原木×2]                ← 最深（基础）
           │ [木板×6]
           │ [木板×4] [木棍×2]        ← 目标配方直接输入
  ─────────┴───────────────
  副产物区： [木板×2] [木棍×2]
  ```
- 最终产物在**左**（竖分割线左侧），材料区在右**从上到下分行横排**（最深→最浅，最后一行=直接输入）。
- **纯图标 + 右下角数量**，无文字、无箭头；目标与材料间**无连线**（已解析的标签用**短连线**连到右侧"所选成员"图标）；悬停图标显示物品栏样式 tooltip（不显示名字，解决长名截断）。
- 多棵树**纵向叠加**；**副产物**（配方批量合成的过量产出）显示在树底部。
- **验收**：栅栏示例数字（栅栏×3、木板×6、木棍×2、原木×2、副产物木板×2+木棍×2）正确。

### 需求 3：多物品合成树（添加 / 删除 / 选择）
- **添加**：配方页"树"按钮（绿=已在树中，点击切换加入/删除）；EMI keybind/树按钮加入悬停/查看物品。**最后一步配方不需默认**；中间材料按 EMI"设为默认配方"拆解。
- **多材料兼容（标签）**：标签材料显示**标签徽记**；未选择具体材料时**不拆解**；点击标签 → 进入可选择具体材料的界面（EMI 原生 ctrl+单击，选择后自动刷新树）。已解析标签在**右侧用短连线连到所选成员**（成员占正常格子，可点击查配方/自动合成）。
- **分解类配方**（铁块→铁锭等）**不自动选用**，避免循环；取消默认的配方不再拆解。
- **组件感知**：同 id 不同组件（不同时长药水等）各自单独开树；持久化保留组件。
- **删除**：右键点击某树最终产物列 → 删除该树。
- **滚动**：惯性 + 可拖动滚动条 + 滚到底钳制 + 仅鼠标在树区时滚动 + 添加后自动滚到底。
- **验收**：添加/删除/持久化（重启仍在）；标签选择后树刷新；铁块/药水正确；滚动符合上述。

### 需求 4：流体显示
- 流体合成（如黑曜石=岩浆+水）正常显示，**消耗量从配方获取**并以 mB 文本标注在流体图标下。

### 需求 5：自动合成（Phase 3，v2.0.0 改纯客户端）
- **操作**：**仅在树模式下悬停右侧最终产物**按快捷键 → 自动合成。**V=合成一次（得最终结果即停）；Shift+V=连续合成（一直合到材料用完）；Ctrl+V=强制合成（缺料跳过、尽力而为）**。
- **V 键范围**：**只在树模式激活且鼠标悬停合成树最终产物（goal）时生效**。非树模式（物品栏/工作台/背包等）或树模式下悬停中间材料/副产物/收藏夹其它物品 → 按 V **无反应**。
- **放料**：复用 EMI `EmiRecipeFiller.clientFill(Destination.NONE)` 一次性放置全部材料（光标受控、形状感知、余料归还），不再逐格点击。
- **合成格 fit 检查**：3×3（shaped）配方需打开工作台界面（2×2 背包不可）；用配方非空输入 bounding box 判定，不用 EMI `canFit`（不可靠）。
- **范围**：**仅工作台配方**（`CraftingRecipe`）；烧炼/锻造/模组机器等一律不自动合成；中间步骤递归自动合成（缺什么先合什么，含标签成员，深度≤6）。
- **规则**：**纯客户端**——用 vanilla 点击包模拟玩家点击当前界面的合成格，**服务端无需装本 mod**；复用 EMI handler（`StandardRecipeHandler`）；无 handler 界面红字"该界面不支持自动合成"；树标红跟随当前界面库存；防环用 EMI 祖先配方栈；无法合成时红字提示；标签材料按 tag 匹配。
- **模组界面取产物**：**AE2 合成终端**结果槽 vanilla 点击取不走（`mayPickup` 恒 false）→ 走 AE2 action 机制（`Ae2Support`，可选依赖，未装 AE2 自动跳过）；取产物后自动清空合成格（防网络补料残留）。**精妙背包**合成产物放回背包**优先堆叠**到同种未满槽（连续合成不散落）。
- **合成成功提示**：用目标配方（`goalRecipe.getOutputs()`）的输出名，不依赖结果槽物品实时 display name。
- **验收**：树模式悬停最终产物按 V 完成完整链条；悬停中间材料/收藏夹物品按 V 无反应；非树模式按 V 无反应；Shift+V 连续；Ctrl+V 缺料跳过静默停。

### 需求 6：产物列左右可调
- **目标**：合成树的**最终产物列可置于左或右**，默认**右**。
- 产物在右时，材料区从左侧镜像排布（分割线在产物列左侧）。
- 新增设置：`treeGoalSide`（产物列左右）。
- **验收**：产物列=右时目标在右侧、材料从左侧排；切"左"镜像正常；EMI 设置页可改且落盘。
- *注：grilling 中用户确认"物品信息会遮挡物品"该条**不做**（忽略）。*

### 需求 7：背景透明可调
- **目标**：合成树背景默认**完全透明**（去掉自绘深色背景，透出下层收藏夹/面板原本背景，与收藏夹一致）。
- 新增设置：`treeBackgroundTransparent`（透明 / 不透明开关，默认透明；关闭恢复现有深色背景）。
- **验收**：默认树区背景透明；开关可切回深色；设置落盘。

### 需求 8：顶部总材料行
- **目标**：合成树**顶部新增一行"底层总材料汇总"**：把当前各叶节点（递归展开到底、但库存已足的不再展开）所需量聚合显示；下方**保留完整分层**（中间产物仍显示）。
- 例：力量药水（金胡萝卜+火药+瓶）在未持金胡萝卜时，顶部总材料行 = 胡萝卜+金粒+火药+瓶。
- 数量取各材料聚合后的总需量（多次引用累加）。
- **验收**：力量药水树顶部为底层总材料行；金胡萝卜等中间产物仍在下方分层显示。

### 需求 9：Shift+树按钮 → 原版 EM 合成树界面 + 左侧产物缩略条
- **共存**：普通点树按钮 = 保持现有"收藏页内容合成树"；**Shift+点 = 打开原版 EM 合成树界面**（`BoMScreen`）。
- 原版界面**左侧叠加自绘产物缩略条**（来自已加入的合成树集合，只画各树最终产物图标）。
- **点击某产物** → 设该产物为 BoM 目标 + 刷新原版树界面，联动展示对应合成树；缩略条高亮当前选中。
- 展示交给原版（EMI BoM 样式）。
- **验收**：Shift+点开出原版界面 + 左侧缩略条；点产物联动切换原版树；普通点行为不变。

### 需求 10：Ctrl+V 强制合成
- **目标**：新增 **Ctrl+V = 强制合成一次**（到自然停）。
- **全链尽力而为**：目标能合就合目标；否则遍历所有中间产物，**只合成材料足够的那步，缺料跳过**；直到没有任何一步可推进才**静默停**（不弹"材料不足"红字）。
- 不新增 Ctrl+Shift+V 连续档（强制模式本身一次到自然停）。
- **验收**：缺料中间产物被跳过、仅合材料够的步骤；无可用步骤时静默结束。

### 需求 11：AE2 终端内自动合成支持网络拉料
- **背景**：AE2 合成终端的库存检测看"网络+背包"，但 **AE2 配置 `exposeNetworkInventoryToEmi` 默认 false** → AE2 的 EMI handler `getInventory` 只返回玩家背包；且 **EMI `clientFill`/`getStacks` 只能从背包槽取物**（`getStacks` 内部用 handler.getInventory 判断可合成 → 背包无料时返回 null 放料失败）。网络材料在"识别"与"放料"两个环节都不可见。
- **目标**：AE2 合成终端内自动合成时，**网络材料可被识别（树标红/预检）且可直接用于放料合成**。
- 方案（javap 实证 AE2 19.2.17）：
  - **识别**：mod 自建"玩家背包槽位 + 网络存储"合并库存（`Ae2Support.mergedInventory`，不依赖 AE2 配置；网络条目经 AE2 `EmiStackHelper.toEmiStack` 转换，组件保真）——树标红、链条预检（`canAfford`/`goalReady`）全链路可见网络。
  - **放料**：AE2 终端走 **AE2 原生 `handler.craft`（transferRecipe）**——`CraftingTermMenu.findMissingIngredients` 查合成格/背包/网络缺料，服务端从**背包+网络**提取材料放进合成格（网络借料机制）；不再用 EMI `clientFill`（其 getStacks 依赖 AE2 配置的 getInventory，网络不可见）。普通界面（工作台/背包/模组界面）仍用 clientFill。
  - **默认配方唯一**：树标红（`canObtain.producersOf`）与链条中间产物（`findProducerToCraft`）都**只用玩家设为默认 / EMI 数据默认配方**（`BoM.getRecipe`），不逐个尝试其它产出配方——默认链断 → 标红/停止（"断了就断了"，尊重玩家配方选择）。
  - **3×3 合成格认可**：`hasCraftingMenuOpen` 同时认可 AE2 合成终端（合成格为 3×3，与工作台等价）→ 中间 3×3 材料在 AE2 终端不误标红。
  - 门禁：AE2 未装时静默关闭（`ModList.isLoaded("ae2")` 短路）。
- **验收**：AE2 合成终端、背包无料仅网络有料 → V 自动合成成功（材料直接从网络进合成格→合成→取产物）；中间层缺料按默认配方链先合中间产物；Shift+V 连续；树标红与默认配方一致（默认链断即红）；AE2 未装环境不受影响。

### 需求 12：树节点 tooltip 明细
- **目标**：悬停树节点时，在原版物品 tooltip 下方追加**合成明细**：
  - `需要: X`（该节点需求数量；流体用 mB/L 单位）
  - `拥有: Y（不足）`（材料节点当前拥有量，不足时红字；目标节点不显示）
  - `由 <产出物名> 合成`（有产出配方时）/ `库存直接获取`（叶节点）
  - `可合成`（绿）/ `材料不足，无法合成`（红）
- **验收**：悬停材料节点可见需求/拥有/配方/可合成性；叶节点显示"库存直接获取"；标红节点显示"材料不足"。

### 需求 13：单次合成数量可配置（会话内）
- **目标**：新增"单次合成数量"（**仅会话内**，默认 1，范围 1-999，重启回 1）——**V 键一次合成 N 个最终产物即停**；Shift+V 连续、Ctrl+V 强制行为不变。
- **调节方式**（树模式下）：
  - **滚轮**：悬停树**最终产物**时滚轮调节（材料区滚轮仍滚动树）；Shift+滚轮 ±10、Ctrl+滚轮 翻倍/减半。
  - **键盘 +/-**（主键盘与数字键盘）：普通 ±1、Shift ±10、Ctrl 翻倍/减半；搜索框输入时不触发。
  - 调节后屏幕顶部提示"单次合成数量: N"。
- **V 键语义**：V=按当前数量合 N 个最终产物（按配方单批输出量累计，如配方一次出 4 个则 N=4 时 1 批即完成）；材料不足时中间层自动补料；目标产物足够 N 个即停（提示"合成成功: X × N"）。
- **树按 N 倍展示**：单次合成数量 N 时，**合成树上的最终产物与材料数量按 N 倍显示**（目标×N、材料需求×N、总材料行/副产物×N，标红按 N 份判断——"实际材料不够"即标红）；调节数量后树实时重建。
- **批量调度（合多个不一份份来回切）**：中间产物按目标剩余需求**一次性攒够**（同一中间配方连续合成直到攒够，如 2 份木门先连续分解 3 原木→木板）；目标材料攒够后**连续合成目标**（每批之间不切回中间），减少配方切换、整体更快。Shift+V 连续同样按批前瞻（每轮攒够 16 批循环）。
- **验收**：滚轮/± 调节数量并提示；树随数量实时放大（材料/产物 N 倍、不足标红）；V 合 N 个即停且先攒中间材料再连续合目标（不再一份份来回切）；Shift+V/Ctrl+V 行为不变；重启回默认 1。

- ~~树模式按住树面板右缘拖动实时调宽、松手落盘~~——**不实现**（已从代码中移除；面板宽度仍由 `treeSidebarWidth` 配置 + EMI 设置页调整）。

### 需求 16（新）：显示能力不失败 + 未知节点语义（2026-08-22 立项）
- **背景**：用户指出"显示能力"是核心功能——EMI 原版任何可悬停配方都能加入收藏并显示合成链（添加=惰性存栈、显示=按需查询、缺失即叶子），而我们的树在"添加"时做**全图严格预解析**（产源只认默认配方、跳过分解类、输入须可转 ItemStack），导致部分配方**无法添加 / 无法显示**。
- **目标**：与 EMI 同语义——**任何可悬停/可显示的配方都能添加，添加永不失败**；未知环节按"叶子"接入并完整参与总材料计数。
- **未知节点定义（javap + EMI 源码 `TreeCost.java` 实证）**：
  - **该材料"需求量"永远已知**（来自父配方输入量，不依赖它自身配方）→ S 总材料照常计入，**不存在"少算"**；
  - **子层展开**可能未知（无配方 / 仅有分解类配方 / 虚拟栈）→ 折叠为叶子，不展开（等价 EMI `recipe==null` 分支直接 `addCost`）；
  - **拥有量**：物品可查；**虚拟栈**（流体/蜜蜂类/自定义）显示"需要量 + 无可用库存"，不显示假 0 / 假 ?。
- **与既有功能的关系**：现有全部已验收路径（全可解析链、S/拥有量/标红/批次、AE2、Productive Bees、自动合成）**行为不变**；改动是"失败→成功"的单向扩张。
- **验收**：能显示而不能添加的配方（虚拟栈产物、分解类中间材料、无注册配方物品）均可添加并显示树；S 完整、状态中立；自动合成已知前缀后停下并给明确提示。

## 3. 非功能需求
- **纯客户端**：服务端不需要装本 mod（v2.0.0 起）。
- 小步推进，每阶段独立验证（`docs/03`）。
- 依赖 EMI **1.1.24 本地 jar**；NeoForge 范围 `[21.0.0,)`（可跑 21.1.x 任意补丁）。

## 4. 配置项（可在 **EMI 设置页**的"EMI Better Synthesis Chain"分组里修改，改动即落盘 `config/emibettersynthesischain-common.toml`）
| 键 | 默认 | 说明 |
|----|------|------|
| `treeSidebarWidth` | 10 | 树模式左侧栏物品列数（宽） |
| `treeRowSpacing` | 16 | 合成树行高（px） |
| `treeItemGap` | 4 | 同行物品间距（px） |
| `treeTreeGap` | 8 | 树间垂直间距（px） |
| `treeByproductGap` | 6 | 副产物区上方间距（px） |
| `treeRedMarking` | true | 悬停树时材料不足节点是否标红 |
| `autoCraftShowTicks` | 6 | 可见合成链每步显示时长（tick） |
| `autoCraftGapTicks` | 2 | 可见合成链步间间隔（tick） |
| `autoCraftFailureMessages` | true | 无法合成时是否红字提示 |
| `treeGoalSide` | right | 产物列在左还是右（`left`/`right`），默认右 |
| `treeBackgroundTransparent` | true | 合成树背景是否透明（默认透明；关闭恢复深色） |
| `treeNumberScale` | 0.5 | 图标上数字（数量/拥有量/流体用量）缩放倍数（0.25-1.0） |
| `treeLineColor` | teal | 线条亮色预设（连接线/树括号/层级序号/S 标记）：青绿/蓝/紫/白/金/红/绿/灰 |
| `treeDividerColor` | teal | 分割线配色预设（目标/材料分割线、副产物横线，取所选预设深色阶），预设同上 |

快捷键键位：`V`（普通合成一次）、`Shift+V`（普通连续）、`Ctrl+V`（强制合成一次），可在按键设置里改绑。
